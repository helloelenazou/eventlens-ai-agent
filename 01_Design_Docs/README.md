# Design Documents / 设计文档

The `ZH` and `EN` folders are localized views of the same EventLens product design. v3.0 adds a shared bilingual interaction layer; business logic, Agent architecture, evidence controls, production-readiness considerations, and acceptance boundaries are intentionally kept aligned across languages.

`ZH` 与 `EN` 文件夹是同一套 EventLens 产品设计的两种语言版本。v3.0 新增统一双语交互层；两种语言共享同一套业务逻辑、Agent 架构、证据控制、生产化关键问题与验收边界。
