# EventLens v3.0 — Bilingual AI Agent

EventLens is a bilingual AI Agent demo for professional buy-side analysts to turn material public-company events into structured impact analysis.

The product combines **materiality triage, multi-source research, completeness checks, fundamental transmission, expectation gap and valuation analysis, portfolio mapping, challenger verification, and an integrated research report** in a 9-stage workflow.

## Highlights

- 🇨🇳 中文 / 🇺🇸 English language toggle
- 9-stage Agent research workflow
- Offline synthetic demo with no API key required
- Live LLM + Web Search mode through a server-side API integration
- Explicit separation of facts, inference, assumptions, and unknowns
- Portfolio-aware analysis without automatic buy/sell instructions
- Challenger / verifier stage for counterevidence and citation checks
- Production-readiness documentation covering retrieval, orchestration, evaluation, governance, permissions, cost, and peak capacity
